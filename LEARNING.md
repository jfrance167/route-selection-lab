# Learning

Longest prefix describes destination containment among installed fixture entries. It does not explain which protocol candidate a device installed or make different protocol metrics comparable.

Equal best does not mean choose the first record. ECMP still needs a packet/flow path-selection mechanism; a fixture group's existence is not that mechanism or evidence of actual load sharing.

Canonicalization is a comparison tool, not a license to discard provenance. Two IPv6 spellings can be one path; changing the route ID/group does not create independent next hops. Host-bit rejection prevents silently rewriting a network declaration.

Discard is an action on the surviving longest entry. Falling back to a shorter route would change the model's behavior. Mathematical membership of network/broadcast addresses remains separate from usable host or permission claims.

Error handling needs process-level tests: a function can return 2 yet the interpreter later report 120 after a second failed flush. An actual closed-pipe test exposed this, and normal/optimized regression checks now verify the process result.
